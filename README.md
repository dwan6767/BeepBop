# BeepBop

A collection of rogue hardware and LoRa experiments. 

I'm building a chain of small, low-power devices. This repo is the landing pad for schematics, code, and logs from the bench. Everything here is open, raw, and meant to be taken apart.

## The Mission
* **Low Power, Long Reach:** Exploring LoRa.
* **Keep It Simple:** No bloat, just the bare metal.
* **Open Source:** If I built it, you can too. Break it, fix it, improve it.
