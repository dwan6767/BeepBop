# BeepBop

A laboratory of open-source LoRa-based embedded devices. This repository documents a chain of experimental hardware projects, designed for learning and exploration.

## Philosophy
*   **Minimalist:** Focused on simple, efficient design.
*   **Experimental:** Built for testing, measuring, and learning.
*   **Open:** Schematics, code, and methodology shared freely.

## Disclaimer
**Experimental Hardware:** Many of these devices are designed for bench testing. Use appropriate equipment (scopes, dummy loads) and operate within legal frequency bands and power limits for your region.
